# Swipe Internship – AI Powered Interview Assistant

An AI-powered interview assistant built with **React (Vite) + Node.js (Express)**.  
It allows candidates to upload their resume, go through an AI-driven interview (React questions),  
and lets interviewers view results in a dashboard.

---

## 🚀 Features
- 📂 Resume Upload & Candidate Info
- 💬 AI Chat Interview with Timed Questions
- ⏱ Timers per question:
  - Easy → 20 seconds
  - Medium → 60 seconds
  - Hard → 120 seconds
- 🤖 AI-generated React.js questions (2 Easy, 2 Medium, 2 Hard)
- 📝 Auto-submit answers when timer ends
- 📊 Score and Summary at the end
- 📋 Interviewer Dashboard for reviewing candidates

---

## 🛠️ Tech Stack
- **Frontend:** React (Vite), Redux Toolkit, Ant Design
- **Backend:** Node.js, Express
- **AI:** OpenAI API
- **Deployment:** Vercel (frontend) + Render (backend)
